## Round 16：删掉角色卡片的预置音色下拉；澄清固化=MiMo voiceclone（00:50）

### 用户疑问：固化是不是小米克隆模型？为什么没有克隆音色 id？设置里没接克隆模型？
查证官方文档（mimo.mi.com / platform.xiaomimimo.com）：
- **是**，固化走 `mimo-v2.5-tts-voiceclone`（finalize 时把试听样本存 voice_assets，
  档案 model 写死 voiceclone、voice_id=`clone:<asset_id>`、voice_asset_id 冻结）。
- **MiMo voiceclone 没有"注册式克隆音色 ID"**：官方接口就是零样本——每次请求都在
  `audio.voice` 里内嵌 `data:{mime};base64,<参考音频>`（≤10MB，mp3/wav）。
  一致性 = 每次合成带**同一份**固化参考音频，不是服务端音色 ID。
  本地 `clone:<asset_id>` 是我们自己的句柄，指向冻结的参考音频文件。
- 设置里不需要"接克隆模型"：voiceclone/voicedesign/预置共用同一 Mimo key+endpoint，
  模型名钉在每条音色档案上；且已有闸门（带样本但模型非 voiceclone → 报错，
  `ensure_model_matches_voice_sample`），不会静默丢样本。
