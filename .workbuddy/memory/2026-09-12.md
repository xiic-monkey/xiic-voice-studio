## 图标迭代：弃「书 + 声波弧」改用「耳机 + 波形条」（老板反馈）

- **问题**：第一版用「三道同心弧」表达声波 → 老板一眼判为**像 wifi**。同心圆弧 + 直边是 wifi 图标的视觉母题，撞得死死的。
- **定稿**：**深蓝渐变底 + 白色头戴耳机 + 中央 5 根高低错落的垂直圆角波形条**。icns md5 `d30990aa31136dbe828f4cc9c1012aca`，已覆盖安装到 `/Applications`（`npx tauri build --bundles app` 51s，`killall Dock` 刷缓存）。
- **中间候选**（三版，都在 `/tmp`）：C 书+波形条、**D 耳机+波形条（选定）**、E 纯波形条。
  - D 选定理由：56px 小尺寸下辨识度最高，耳机轮廓大、不糊。老板自己挑的。
  - C 更点题「有声书」但小尺寸下书页细节偏碎；E 太通用（像通用音频播放器）。
- **设计教训（可复用）**：**给音频类 app 做图标，永远用垂直波形条，不要用同心圆弧/扇形弧**——后者在 16~56px 下必然被读成 wifi 或音量图标。
- 旧的「书+弧」图标备份在 `/tmp/voice-icon-old-backup`（临时目录）。
- 圆角后处理脚本：`/tmp/make_icon.py`（另存于 skill `tauri-app-icon-replace/scripts/make_icon.py`）。

## 直接启动 Tauri 原生窗口（实测）
- 用户要"直接tauri启动"看原生窗口。排查发现当时 `pnpm tauri dev` 会话在跑，但其拉起的 Rust 二进制（pid 60060）是**无窗口僵尸**（osascript 窗口数=0），屏幕看不到。
- `kill 60060` 连带带走 tauri dev 父进程(26283) 与 Vite(26460)，dev 环境清空。
- `/Applications/xiic-voice-studio.app` 实测**不存在**（上面图标段记录的"已覆盖安装"当时为真，但现在已失效/被清），`open` 报文件不存在。
- 改用分离方案重建：后台 `pnpm dev`（Vite :1420 常驻）+ 直接拉 `./src-tauri/target/debug/xiic-voice-studio`。osascript 窗口数=1，原生 Tauri 窗口成功弹出。
- 结论：日常预览走 Vite+debug 二进制分离方案最稳；release 安装版当前不在 /Applications，需要时再 `pnpm tauri build` 生成。
